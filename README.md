# แอป "กันลืม" (Kan Luem - Sticky Notes Reminder) 📌

เว็บแอปพลิเคชันจดบันทึกรายการที่ต้องทำกันลืม ออกแบบสไตล์ **แผ่นโพสต์อิท (Post-it)** สีสันสดใส ตัวหนังสือใหญ่ อ่านง่าย สบายตา เหมาะสำหรับเปิดใช้งานบนสมาร์ทโฟนและคอมพิวเตอร์

---

## 🌟 ฟีเจอร์เด่น
1. **ดีไซน์กระดาษโน้ต Post-it**:
   - แยกตามการ์ดสีสันพาสเทล (เหลือง, ฟ้า, เขียว, ชมพู, ส้ม, ม่วง) ปรับเปลี่ยนสีกระดาษได้ตามใจ
   - ตัวหนังสือขนาดใหญ่พิเศษ (Large Typography) อ่านง่ายชัดเจน ออกแบบให้เหมาะกับการใช้งานด้วยมือเดียวบนมือถือ
2. **เรียงลำดับตามวันที่ต้องทำ**:
   - จัดเรียงรายการที่ต้องทำจากใกล้สุด (วันนี้, พรุ่งนี้, อีกกี่วัน) ไปไกลสุดโดยอัตโนมัติ
   - ป้ายบอกสถานะแบบสดใส: `🔥 วันนี้`, `พรุ่งนี้`, `⚠️ เกินกำหนด`, `📅 อีก X วัน`
   - แถบตัวกรองด่วน: ทั้งหมด / วันนี้ / เร็วๆ นี้ / เสร็จแล้ว
3. **ช่องทางบันทึกข้อมูล 3 รูปแบบ**:
   - ⌨️ **พิมพ์ (Typing)**: พิมพ์หัวข้อ รายละเอียด กำหนดวันที่และเวลา
   - 🎙️ **เสียง (Voice)**:
     - **แปลงเสียงพูดเป็นข้อความภาษาไทย (Speech-to-Text)**: กดปุ่มไมค์ 🎙️ แล้วพูดภาษาไทย ข้อความจะพิมพ์ลงโน้ตให้อัตโนมัติทันที
     - **อัดคลิปเสียง (Voice Memo)**: บันทึกเสียงเตือนความจำสั้นๆ ไว้ในการ์ดเปิดฟังซ้ำได้
   - 📸 **รูปถ่าย (Photo)**:
     - ถ่ายรูปตรงจากกล้องมือถือ หรือเลือกรูปจากคลังภาพมาแนบไว้บนแผ่นโน้ตได้
     - แตะที่รูปเพื่อเปิดดูแบบเต็มหน้าจอ (Full-screen)
4. **ความปลอดภัยและออฟไลน์**:
   - บันทึกข้อมูลด้วย **IndexedDB** ภายในเครื่องทั้งหมด ไม่ต้องต่อเน็ตก็ใช้งานได้
   - มีปุ่ม **💾 สำรองข้อมูล (Backup & Restore)** สำหรับ Export/Import เป็นไฟล์เก็บไว้หรือย้ายเครื่อง

---

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดบนคอมพิวเตอร์ (PC / Mac)
- เพียงดับเบิลคลิกที่ไฟล์ `index.html` หรือคลิกขวาแล้วเลือก **Open with Google Chrome / Microsoft Edge** ก็สามารถใช้งานได้ทันที ไม่ต้องติดตั้งโปรแกรมใดๆ

### 2. วิธีนำไปเปิดและติดตั้งเป็นไอคอนบนสมาร์ทโฟน (มือถือ)
- **วิธีที่ 1 (แชร์ไฟล์ / อัปโหลดขึ้นเว็บฟรี เช่น GitHub Pages / Netlify / Vercel)**:
  - นำไฟล์ทั้ง 3 ไฟล์ (`index.html`, `style.css`, `app.js`) ไปวางบนโฮสติ้งฟรี (เช่น GitHub Pages)
  - เปิดลิงก์บนมือถือผ่าน Chrome (Android) หรือ Safari (iOS)
- **วิธีที่ 2 (เพิ่มเป็นไอคอนแอปบนหน้าจอมือถือ - Add to Home Screen)**:
  - บน **iPhone (Safari)**: กดปุ่มแชร์ (Share Icon สี่เหลี่ยมลูกศรชี้ขึ้น) -> เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
  - บน **Android (Chrome)**: กดจุด 3 จุดมุมขวาบน -> เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
  - จะได้ไอคอนแอป "กันลืม" บนหน้าจอมือถือ เสมือนเป็นแอปพลิเคชันจริง เปิดใช้งานได้เต็มจอและสะดวกสบาย!
